# ThongVNMC Studio

> **ThongVNMC Studio** (also known as **MinhthongVNMC Studio**) is a group/studio focused on content creation and map building, well-known within the Minecraft Java/Bedrock Edition gaming community.

## History

* **April 4, 2025:** ThongVNMC Studio created an account on TikTok.
* **May 8, 2025:** ThongVNMC Studio created its YouTube account.
* **July 14, 2025:** ThongVNMC Studio registered with Planet Minecraft to become a creative developer, with its products set to be released on this date.
* **August 8, 2025:** Modbay and WFHMC City returned to normal operation.
* **September 13, 2025:** Addressed ongoing issues regarding TikTok’s age-restriction feature affecting direct messages and community support.
* **December 2025:** ThongVNMC Studio created its first GitHub repository.
* **January 17, 2026:** Account deleted; official comeback launched shortly after via Modbay (search "WFHMC City").
* **February 25, 2026:** Renamed "MinhthongVNMC" to "MinhthongVNMC Studio", later updated to "MinhthongVNMC ˢᵗᵘᵈⁱᵒ".
* **June 10, 2026:** Launched a new Gmail address to provide support for WFHMC City users for issue reporting and assistance.
* **September 3, 2026:** Registered with Minecraft Maps as a creative developer, with its first product scheduled for release.
* **October 7, 2026:** Official name change from "MinhthongVNMC ˢᵗᵘᵈⁱᵒ" to "ThongVNMC ˢᵗᵘᵈⁱᵒ".
