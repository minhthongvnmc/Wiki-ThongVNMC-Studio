## History

- **April 4, 2025:** ThongVNMC Studio created its official TikTok account.
- **May 8, 2025:** ThongVNMC Studio launched its official YouTube channel.
- **July 14, 2025:** ThongVNMC Studio registered as a creator on Planet Minecraft, with projects scheduled for public release.
- **August 8, 2025:** Modbay and the *WFHMC City* project returned to normal operations.
- **September 13, 2025:** Addressed TikTok age-restriction issues affecting direct messaging and community support channels.
- **December 2025:** ThongVNMC Studio created its first GitHub repository.
- **January 17, 2026:** Following account disruption on January 17, an official comeback was announced with *WFHMC City* redistributed on Modbay.
- **February 25, 2026:** Rebranded from "MinhthongVNMC" to "MinhthongVNMC Studio", later stylized as "MinhthongVNMC ˢᵗᵘᵈⁱᵒ".
- **June 10, 2026:** Launched a dedicated support email address for *WFHMC City* users to handle issue reports and community inquiries.
- **September 3, 2026:** Registered as a creative developer on Minecraft Maps, scheduling its first platform release.
- **October 7, 2026:** Officially changed name from "MinhthongVNMC ˢᵗᵘᵈⁱᵒ" to "ThongVNMC ˢᵗᵘᵈⁱᵒ".
